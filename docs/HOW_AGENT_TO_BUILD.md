# 项目构建介绍

项目名称：GayBarTools
这是一个学习通自动刷课软件，实现自动化处理课程。

## 参考

- 1、./Example1.mp4，该视频展示了章节类型为视频的点击流程，其中视频播放过程被跳过（视频中使用 OBS 录屏的过程请忽略）
- 2、./Example2.mp4，该视频展示了章节类型为静态页面浏览的点击流程（视频中使用 OBS 录屏的过程请忽略）
- 3、./Example3.mp4，该视频展示了章节类型为视频时，视频中间被插入答题时的点击流程（视频中使用 OBS 录屏的过程请忽略）
- 3、学习通个人主页：https://i.chaoxing.com/

## 软件特征要求

- 1、使用 Python 以及其相关库编写
- 2、打开网页在 Linux 上使用 Chromium 或者 Edge ，在 Windows 上使用 Chromium、Chrome 或者 Edge
- 2、可接入 OpenAI 兼容格式的 LLM API
- 3、可使用 OCR 图像识别的方式让 LLM 识别屏幕内容
- 4、可模拟鼠标点击，而且实现方式要有一定的反检测能力
- 5、软件隔离的浏览器沙箱可以保存 Cookie 到项目文件夹，以方便用户不必反复登陆学习通

## 软件工作流程

- 1、在软件前端界面点击特定按钮后，拉起浏览器窗口
- 2、用户手动打开学习通网站界面，并点击进入任意课程的任意章节
- 3、在用户点击前端中的开始刷课按钮后，开始识别当前章节课程类型，存在视频类型（Example1.mp4 中展示）和静态页面浏览类型（Example2.mp4 中展示）两种
- 4-1、若识别类型为视频，则需要软件模拟点击播放键，如果视频中间被插入答题界面（Example3.mp4 中展示），调用图像识别并调用 LLM 答题，模拟点击正确答案后继续播放（网页在答对题目后会自动继续播放），待播放完毕（全程不可快进和跳过）后，模拟点击网页中右下角“下一节”按钮，进入步骤五
- 4-2、若识别类型为静态页面浏览，则需要软件模拟点击滚动条，拉到最下方，随后模拟点击网页中右下角“下一节”按钮，进入步骤五
- 5-1、如果跳转到的页面为本节的答题页面，调用图像识别并调用 LLM 答题，模拟点击正确答案后提交，再点击右下角“下一节”按钮
- 5-2、如果跳转到的页面并非答题页面，则再次进入步骤三进行下一轮循环
- 6、5-1 步骤完成后，再次进入步骤三进行下一轮循环

## 软件开发要求

- 1、所有开发过程中使用和生成的文件全部放在项目文件夹下和 /tmp 公共缓存文件夹
- 2、不允许在开发过程中污染用户的环境
- 3、当用户环境中不存在符合条件的浏览器时，可以自行下载 Chromium 放在工作环境内使用

## 软件运行要求

- 1、软件不能在项目文件夹和 /tmp 以外的地方生成任何文件，所有需要持久存储的文件都应该放在项目文件夹中
- 2、软件在工作时绝对不能污染用户的环境，包括用户的浏览器配置等（不包括浏览器缓存）

## 备注

- 软件开发中未涉及到的问题可以适当自由发挥
